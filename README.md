## 📖 About the Project

**Integration-Day-CataLeet** is a website developed to present and organize the planning of Integration Days for a club event at **1337 Coding School**.

The website provides participants with an organized overview of the event schedule, helping them discover planned activities and understand how the different activities are structured throughout the integration days.

The main goal was to create a simple, accessible, and user-friendly interface that makes event planning easier to explore.

## ✨ Features

- Event schedule presentation.
- Organized activities and planning.
- Clear presentation of integration-day events.
- Interactive user interface.
- Dynamic interactions using JavaScript.
- Responsive layout for different screen sizes.

## 🛠️ Technologies Used

| Technology | Description |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layout, and visual design |
| JavaScript | Interactive functionality and dynamic behavior |

## 🚀 Installation & Usage

```bash

```

Open the `index.html` file in your preferred web browser.

No additional dependencies or installation steps are required.
